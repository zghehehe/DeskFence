它替你做好的六件事

自动分类

按文件类型把桌面图标分进"文档 / 图片 / 软件"等栅栏;新文件落下自动入位,无需手动整理。

原生级观感

图标、字距、ClearType 文字与系统阴影全部与 Windows 原生桌面逐像素一致——不凑近看,分不出哪个是栅栏。

换壁纸零感知

栅栏背景实时透出真实壁纸:换壁纸、用带时钟的动态壁纸,栅栏区域与周围桌面同帧切换,没有旧色块残留。

无边框,悬停浮现

平时完全隐形,只留下整齐的图标。鼠标扫过栅栏,边框、标题与四角手柄才浮现,此时可以拖动、缩放。

拖拽即归类

把图标从一个栅栏拖到另一个就完成分类转移,松手才落位、其余图标纹丝不动;拖到回收站即删除。

稳如老狗

Explorer 崩溃重启、系统休眠唤醒、误杀进程,都能自动恢复;异常退出后原生桌面自动还原,绝不留白屏。

使用文档

四步,从乱到净

每一步都有动画演示,跟着点就行。

第 1 步

启动即自动分类

双击 deskfence.exe,一秒内桌面完成接管:图标按类型分入栅栏,原生图标隐藏,任务栏不增不减。

  • 首次运行 在系统托盘出现图标,悬停显示 DeskFence
  • 无需配置 —— 默认就是最接近原生桌面的"精确渲染"
  • 想还原? 托盘右键 → 显示原生桌面 / 退出
启动后:图标归入栅栏,原生桌面图标自动隐藏
第 2 步

悬停浮现,拖角缩放

平时栅栏是隐形的,桌面只剩整齐图标。把鼠标移到图标区域,边框和四角手柄浮现:

  • 拖边框 → 栅栏移到新位置(自动吸附对齐)
  • 拖四角 L 形手柄 → 等比放大缩小
  • 点标题旁倒三角 ▾ → 操作菜单(改名/折叠/锁定/删除)
  • 鼠标移开后自动隐身,桌面回归干净
边框 + 四角 L 手柄 + 标题:悬停才出现
第 3 步

拖一下,完成归类

图标拖到哪里,就归到哪类。拖动过程中其余图标纹丝不动,一条插入线提示落点,松手才重新排列。

  • 跨栅栏拖动 → 分类转移
  • 拖到回收站 → 删除文件
  • 按住拖空白处 → 框选多个图标批量移动
插入线提示落点;其余图标松手前完全不动
第 4 步

托盘菜单,一切可调

点击任务栏托盘的 DeskFence 图标,打开总控菜单:

  • 渲染模式:精确(默认,与原生逐像素一致)/ 透明(兼容特殊环境)
  • 对齐模式:网格吸附 / 自由摆放
  • 自动分类:新文件自动入栅栏,可随时开关
  • 显示原生桌面:临时退回原生状态查看
  • 开机自启 / 使用说明 / 退出
所有开关集中在一处,勾选即时生效

常见问题

没找到答案?托盘菜单 → 使用说明。

我的文件会被移动或修改吗?

不会。DeskFence 只接管"图标的显示方式",文件本身始终留在桌面目录原位,退出后连摆放位置都原样恢复。

会影响系统性能吗?

不会。空闲时几乎零活动:渲染仅在悬停、文件变化、壁纸切换等事件发生时进行;内存占用约 80MB,无后台联网,无服务注入。

换壁纸、用动态壁纸会有问题吗?

不会。栅栏背景"实时透出"真实壁纸(与原生图标层同原理),静态、幻灯片、带时钟的动态壁纸都逐帧跟随,文字与阴影保持稳定。

怎么还原原生桌面 / 卸载?

托盘菜单 → "显示原生桌面"临时还原;退出即完全恢复。删除 deskfence.exe 即完成卸载——不写注册表残留,不装驱动服务。

双击后没反应?

程序可能已在后台运行(单实例)。再双击一次会唤醒它显示全部栅栏;或检查托盘是否已有 DeskFence 图标。紧急情况运行 deskfence.exe --restore-desktop 恢复原生桌面。

支持多显示器吗?

支持。每个显示器的桌面区域都会被接管,栅栏可在各屏之间自由摆放,DPI 不同的混合屏幕也没问题。

和 Fences 等同类软件比有什么不同?

DeskFence 追求"无感":图标和文字与原生桌面像素级一致、启动无中间态、换壁纸零残留,并且完全免费、纯本地、无订阅。
