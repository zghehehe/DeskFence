1安装与启动

无需安装,双击即用。

  1. 双击 deskfence.exe,约 1 秒后桌面自动完成整理——原生散落的图标消失,取而代之的是按类型分好的栅栏。
  2. 想开机自动运行:打开托盘菜单,勾选「开机自启」。
  3. 再次双击 exe 不会开第二个实例,只会把已隐藏的栅栏重新显示出来。
💡 DeskFence 是单文件绿色软件,放在任何目录都可以;放好后不要再移动位置,否则开机自启会失效(可在托盘菜单重新勾选一次)。

2自动分类:文件自己回家

默认模式,开箱即用。

桌面文件按类型自动进入对应栅栏,某类栅栏不存在时会在该类第一个文件出现时自动创建:

栅栏收集的文件类型
🖥 软件exe / msi / lnk / bat 等程序与快捷方式
📁 文件夹所有目录
📄 文档txt / md / Office / PDF 等
🖼 图片jpg / png / gif / svg 等
🎬 媒体mp3 / wav / mp4 / mkv 等音视频
💻 代码py / js / ts / rs / go / c / cpp / html / json 等
📦 压缩包zip / rar / 7z / tar / gz 等
❓ 其他以上未覆盖的类型
💡 回收站图标固定显示在「软件」栅栏第一位,把文件拖上去即删除,和原生桌面一样。

3拖拽整理:随手一拖就位

被拖的图标跟手移动,其他图标纹丝不动,松手才重排。

  • 调整顺序:按住图标拖到目标位置,出现插入线后松手。
  • 跨栅栏转移:拖到另一个栅栏上松手,文件即改换分类(自定义分类模式下即完成"归档")。
  • 删除:拖到回收站图标上松手。
  • 拖动中按 Esc 取消,一切还原。
  • 拖动栅栏本身(标题区)可以移动栅栏;靠近边缘自动吸附,靠近其他栅栏自动保持间距;栅栏之间出现插入线可调换顺序。
💡 悬停高亮也有——鼠标在图标上停留约 0.4 秒出现高亮,和原生桌面手感完全一致。

4文件操作:双击、右键、重命名

所有操作与原生桌面同源。

  • 打开文件:双击图标,与在桌面双击完全一致。
  • 右键菜单:打开、打开方式、复制、删除、属性……与原生逐项一致(含系统第三方扩展)。
  • 重命名:右键 → 重命名,或选中后按 F2,在原图标位置就地编辑,回车确认、Esc 取消。
  • 多选:Ctrl 点选、Shift 连选、空白处按住左键框选。
  • 滚轮:栅栏内容超出时滚动查看。

5栅栏管理:折叠、锁定、新建、删除

点栅栏右上角的「倒三角」打开管理菜单。

  • 折叠 / 展开:临时收起栅栏只留标题条,再点一次展开。
  • 锁定:锁定后栅栏位置不可拖动,防误碰。
  • 排序方式:常用(按使用频率)/ 最近修改 / 名称 / 手动(完全由拖动决定)。
  • 自定义分类模式:托盘菜单取消勾选「自动分类」后,文件不再按类型归类——拖进哪个栅栏就属于哪个栅栏,未分配的集中在「未分类」;右键标题可重命名 / 删除栅栏。重新勾选「自动分类」即回到 8 类模式。
  • 调整大小:拖动栅栏边缘/四角;高度不足时自动出现滚动条。

7安全与还原:来去干净

DeskFence 只"接管显示",从不移动或修改你的文件。

  • 所有文件仍原封不动地放在桌面目录里,用资源管理器打开桌面看到的就是原样。
  • 退出、卸载、结束进程,桌面立刻恢复原生图标。
  • 即使程序异常崩溃,下次启动也会检测到并自动恢复原生桌面;极端情况下可运行 deskfence.exe --restore-desktop 一键自救。
  • 布局与偏好保存在 %APPDATA%\DeskFence\,删除该文件夹即完全清除痕迹。
⚠ 唯一需要注意:使用 Wallpaper Engine 等动态壁纸软件时,请在托盘菜单把渲染模式切换为「透明」,以获得最佳兼容性。

FAQ

常见问题

我的文件会被移动或修改吗?

不会。DeskFence 只接管"图标的显示方式",文件本身始终留在桌面目录原位。退出即恢复原生桌面,位置都不变。

双击后没反应?

程序可能已在后台运行(单实例)。再双击一次会唤醒它显示全部栅栏;或检查任务栏托盘是否已有 DeskFence 图标。

和 Fences 等同类软件比有什么不同?

DeskFence 追求"无感":图标和文字与原生桌面像素级一致、启动无中间态、退出零残留,并且完全免费、纯本地、无任何订阅。

支持多显示器吗?

支持。每个显示器的桌面区域都会被接管,栅栏可在各屏之间自由摆放。

桌面文件很多,性能会慢吗?

图标像素有缓存,文件变更只增量刷新;稳态下每秒只做一次轻量自检。几百个文件的桌面依然流畅。
