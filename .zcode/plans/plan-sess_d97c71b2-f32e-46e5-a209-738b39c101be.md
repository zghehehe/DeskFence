# 拖拽/对齐管线推倒重做：统一为"磁吸 + 插入线 + 原位放置"模型

## 背景与回滚范围

三轮叠加修补（实时中心判定 → pack_rows_vertical → 边界最近模型 + 带内重排）互相打架，导致你实测的：下层移不进、无插入线、上层空不出距离、首栅栏不贴左等混乱。**全部回滚**，保留本会话已验证好的部分：

**保留（不再动）**：拖动 1:1 跟手（陈旧过滤豁免 + 便宜 present）、拖动中不做抗重叠（死区根源已除）、boot 缺类建栏、md→代码 分类、托盘"显示栅栏边框线"。

**回滚/替换**：`fence_insertion_plan`（边界最近版）、松手"带内 x 重排"、`pack_rows_vertical`（删除——它强制全局收行，正是"空不出距离"的元凶）、`reflow_chain_flow`（简化）、槽位尺寸继承（宽度变化的元凶）。

## 新模型（按你的三个回答设计）

**核心原则：不再有任何全局自动重排。对齐感全部来自"吸附"——距离固定间距位置一个阈值内就吸过去，其余时候保留你摆的位置（允许大间隙）。**

### 1. 拖动中（自动/网格档）
- 1:1 跟手（现状保留）。
- **插入线**：行带聚类（任意层数通用）后，候选槽位=带内相邻成员之间（整个间隙区段可激活，宽窄都能落）、带首/带尾、跨层时另一层的对应位置；取距被拖栅栏实时中心最近者。原矩形(外扩 GAP)内不显示。**首行上方/末行下方超出 0.6 倍栅栏高 = 无线（自由区）**。
- **磁吸**：槽位激活时计算该槽位的吸附矩形（与左/右/上/下邻居保持固定 GAP 的位置），距离小于 SNAP_THRESHOLD 就把被拖栅栏吸过去（拖走即恢复跟手）——这就是你说的"到一定距离自动吸附到固定距离"。
- 保留既有的工作区四边吸附（贴顶/贴左由此实现）。

### 2. 松手
- **有插入线**（含"松手瞬间滑出容差"用 `Drag.last_insert` 兜底）：**位置轮转**——只轮转 x/y，尺寸永远是各自的（宽度变化根治）；未受影响的栅栏位置不动；不做任何全局重排（大间隙保留）。
- **无插入线**：原地自由放置——夹屏 + 邻居吸附（靠得近就对齐固定 GAP）+ 抗重叠（只在真重叠时最小位移推开）。不重叠就不动任何人 → 空开距离合法。
- 保存 + 刷新（现状保留）。

### 3. 新建栅栏落位
`reflow_chain_flow` 删除，替换为：新栅栏放工作区左上角 (vx, vy)，`avoid_overlap` 推到不重叠处——贴顶贴左，被推也保持固定间距。

### 4. 纯几何函数下沉 model.rs + 单元测试（本次防回归的关键）
- `rows_from_rects`：行带聚类
- `nearest_slot`：最近槽位（用例：窄间隙、宽间隙、跨层、三层、原位抑制、自由区）
- `rotate_positions`：位置轮转（用例：尺寸不变、无关者不动、跨层轮转）
- 新增用例锁死：移动不改宽高、松手后无关栅栏 x/y 不变

## 风险
- 拖动中磁吸与跟手的叠加手感需你实测调阈值（初始 SNAP_THRESHOLD 沿用现值，不适再调）
- 轮转只动位置，跨尺寸换位后行内宽度分布改变——不再做视觉重排，行可能呈现大小栅栏混排（这是"保留间隙"的必然取舍）
