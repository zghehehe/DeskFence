⓪ 渲染模型(先读这个)ink 常驻:2026-08-26 起,两种渲染模式共用

栅栏窗口是 WS_EX_LAYERED 分层窗口,内容 = 透明底 + 1/255 隐形命中层 + 图标 + 墨水文字。真壁纸从窗口底下由 DWM 逐帧透出——换壁纸时背景与桌面同帧跟随,栅栏无需任何"换底"动作。

背景:透出,不持有

栅栏不烙壁纸像素。整面铺 alpha=1/255 的隐形底(ULW 按逐像素 alpha 命中,没有它空白区会点击穿透),其余透明。

draw_fence

文字:seeded GDI ClearType

标签矩形先垫"种子"(快照壁纸色+覆盖层合成),DrawShadowText 烘焙(与 Explorer 同源),仅"有墨水"像素不透明。阴影像素反推覆盖率输出纯黑 alpha 墨——背景无关,换壁纸瞬间即精确。

gdi_draw_labels_seeded

壁纸快照的角色:种子

PrintWindow 快照不再做背景,只给文字烘焙提供底色 + 精确模式启动守卫。种子晚到无视觉代价(阴影已背景无关,重烘焙仅 1px 字形边缘)。

ensure_wallpaper / wallpaper.bin

两种模式

precise(默认):等首帧种子就绪再呈现第一帧。transparent:立即呈现,黑种子兜底。渲染管线完全相同,菜单两档只是守卫差异。动态壁纸强制回退已退役;仅"捕获反复失败+无快照"回退透明。

precise_mode_on

③ 渲染链路一次 refresh_fence_impl 的完整流水线

refresh_fence(id)触发源:悬停提交/文件变更/模式切换/拖拽结束/栅栏移动…
启动守卫精确模式 && 种子空 && 无拖拽 → 跳过呈现(保旧帧/保原生桌面)
表面管理尺寸变了才重建 D2D 表面,否则复用create_surface
D2D 绘制1/255 隐形底 + 图标(DrawIconEx)+ 悬停/选中态 + 滚动条;chrome(边框/标题/四角手柄)仅悬停或拖拽中绘制render::draw_fence
seeded GDI 文字EndDraw 后垫种子 → DrawShadowText(ClearType+阴影)→ 墨水化:阴影=覆盖率纯黑墨,字形=不透明,其余恢复透明render::gdi_draw_labels_seeded

无边框常显(2026-08-26):默认态完全干净(无边框/标题/底色),悬停或拖拽时 chrome 浮现(边框+四角 L 形手柄+标题+淡底)。悬停复用 fence_hover 的 400ms 延迟提交(防闪血统);命中与缩放热区是位置判定,与可见性无关。

④ 壁纸管线事件驱动;稳态捕获已"懒化+节流"到最低限度

信号源(任一触发)① WM_SETTINGCHANGE 手动换壁纸(毫秒) ② Themes 目录 watcher 幻灯片轮换 ③ IDesktopWallpaper 签名轮询(1s,标准机器) ④ 10min 稳态兜底tray_wndproc · start_wallpaper_watcher · wallpaper_signature
懒捕获门槛壁纸失效后:距失效>1.5s(DWM 淡入结束)且 >5s 无交互才捕获;常规刷新 2.5s 推迟wallpaper_dirty_since / LAST_INTERACTION_MS
捕获PrintWindow 拍宿主;原生图标可见时临时隐藏防"图标烙进快照";过渡黑帧跳过(不算失败)ensure_wallpaper
区域感知比对只比栅栏覆盖区域内的像素(容差 8/通道):栅栏外变化(时钟壁纸分钟跳动)不再触发重绘与落盘wallpaper_changed_under_fences
变了 → 整帧重绘refresh_all_fences + 快照落盘 wallpaper.bin;没变只更新种子(无感)
回退守护:只有真实失败(PrintWindow 报错)累计、当前无任何快照且过 10s 启动宽限,才回退透明模式落盘(动态壁纸检测已退役——统一渲染后降级无意义且会静默改写配置)。为什么稳态 10min:ink 常驻后快照只作种子,不新鲜无视觉代价;而每次 PrintWindow 都强制宿主重绘,是交互窗口期闪的来源——能不跑就不跑,真实变化由事件毫秒级跟随。
