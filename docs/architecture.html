① 启动链路双击 exe → 桌面被栅栏接管(目标:1 秒内、无中间态)

要点:shell 调用(显示名/图标)全部后台并行,主线程只做配置与壁纸缓存加载;首帧必须是"带 ClearType 阴影的最终帧",没就绪就保持原生桌面。
双击 deskfence.exe单实例互斥体检查main.rs acquire_single_instance
已有实例?是 → 唤醒旧实例显示全部栅栏后退出ui::notify_second_instance
init()per-monitor DPI、COM STA、D2D 渲染器、实测图标格距ui::init · log "boot init done"
startup() 并行分流后台线程A:显示名解析(4线程) / 后台线程B:图标提取(4线程)shell::finalize_scan / prewarm_icon_cache
主线程同时加载布局配置 → 壁纸缓存(wallpaper.bin,~50ms) 或现场暖场捕获 → 渲染器预热(烧掉 D2D/GDI 首次成本)load_wallpaper_cache / warm_renderer_scratch
join 后台线程合并文件列表+图标缓存;首帧绘制全部缓存命中
show_all_fences()创建/挂接窗口(插到桌面宿主之后)→ 绘制 → ULW 呈现log "boot first fence presented gdi_labels=true"
reconcile_desktop_icons栅栏呈现验证通过 → 隐藏原生图标(原子切换)log "desktop icons hidden after fence presentation verified"
托盘+钩子+watcher托盘窗口/菜单宿主/键盘鼠标钩子/桌面与壁纸目录 watcherinit_tray · start_desktop_watcher · start_wallpaper_watcher
进入消息循环 GetMessage 分发到 fence/tray/guide 三个 wndprocui::run_message_loop · log "boot done"
首帧守护:精确模式下壁纸快照未就绪时 refresh_fence_impl 直接跳过呈现(保留原生桌面),由 200ms 追赶定时器(TIMER_WALLPAPER_CATCHUP)捕获成功后一次到位。绝不能先画 D2D 文字帧再切换——那就是历史上"阴影迟到/闪变"的根因。

② 窗口与 z 序结构谁浮在谁上面

TOPMOST band
拖拽指示 overlay(guide 窗口) · 全屏分层 · 仅拖拽期间有内容
普通窗口 band
用户的浏览器/办公软件等一切普通窗口
桌面层(z 链)
栅栏窗口 ×N(WS_EX_LAYERED,紧贴宿主正上方连续排列) · 1px 菜单宿主与托盘窗口(点击穿透,屏幕角落,容忍于 z 链判定)
桌面宿主
Progman / WorkerW(SHELLDLL_DefView 的图标列表按需隐藏)
最底层
壁纸(DWM 绘制;精确模式栅栏背景=它的快照)
z 序自愈(每秒):ensure_all_attached 做整链就位判定——宿主上方窗口之下恰好是全部栅栏才跳过 SetWindowPos;否则重排一次。绝不逐窗口无条件重申(历史上的"每秒洗牌"会在前台 band 变化后变成真实移动=闪屏)。

③ 渲染链路一次 refresh_fence_impl 的完整流水线

refresh_fence(id)触发源:悬停提交/文件变更/模式切换/拖拽结束…
守卫检查精确模式 && 快照空 && 无拖拽 → 跳过呈现(保旧帧/保原生桌面)
表面管理尺寸变了才重建 D2D 表面,否则复用create_surface
D2D 绘制壁纸快照裁剪(精确)或透明底 + 图标(DrawIconEx)+ 标题/滚动条 chromerender::draw_fence
GDI 文字EndDraw 后用 DrawShadowText 画图标名(ClearType+阴影,与原生逐像素一致)render::gdi_draw_labels
ULW 呈现UpdateLayeredWindow 上屏,标记 presentedrender::present_surface
透明模式:无快照时跳过壁纸裁剪与 GDI,文字走 D2D(动态壁纸环境自动回退,托盘菜单"渲染模式"可手动切换;运行中捕获反复失败也会自动回退并落盘)。

④ 壁纸管线信号驱动,60s 兜底

信号源(任一触发)① WM_SETTINGCHANGE 手动换壁纸(毫秒) ② Themes 目录 watcher 幻灯片轮换 ③ IDesktopWallpaper 签名轮询(1s,轮换) ④ 60s 兜底轮询tray_wndproc · start_wallpaper_watcher · wallpaper_signature
防撞车交互(菜单开/关、点击)后 2.5s 内推迟捕获mark_interaction / LAST_INTERACTION_MS
捕获PrintWindow 拍宿主;原生图标可见时临时隐藏防"图标烙进快照"ensure_wallpaper
容差比对与现用快照差 >8/通道 才算变化(捕获亮度有 ±4% 时序波动)wallpaper_content_changed
变了 → 整帧重绘refresh_all_fences + 快照落盘 wallpaper.bin
回退守护:切换过渡期的纯黑帧不算失败;只有真实失败(PrintWindow 报错)累计且当前无任何快照且过 10s 启动宽限,才回退透明模式落盘。换壁纸后黑帧/保留旧快照都是正常路径。

⑤ 菜单链路倒三角 / 托盘 / 文件右键,三条入口一套机制

入口① 点倒三角(handle_lbuttondown Hit::Collapse) ② 托盘图标左/右键(TRAY_MSG 回调) ③ 文件图标右键(IContextMenu)
track() 打开前清全部悬停状态并熄灭已亮卡片(点击反馈,菜单期间栅栏静止)ui::track
前台化菜单宿主SetForegroundWindow(1px 菜单宿主),失败则 AttachThreadInput 借权限重试;菜单后补 WM_NULLshell::menu_foreground
TrackPopupMenu模态循环;期间栅栏消息被推迟(关闭后的陈旧 mousemove 会被光标校验丢弃)
点菜单外任意处 / Esc / 切换窗口菜单关闭并派发命令dispatch_tray_command / fence_menu 后续
三个禁区(全部踩过):owner 不能用栅栏窗口(z-band 提升被拉回=闪)、不能 WS_EX_LAYERED(动画损坏成两段跳)、1px 宿主不能压在栅栏上(DWM 失活波及下方分层窗口)。菜单关闭后栅栏区域偶现 ~4% 亮度抖动是 DWM 对被遮挡分层窗口的舍入差,低于感知阈值,不是缺陷。

⑧ 自愈链路每秒 tick(global_tick)

WM_TIMER(TIMER_GLOBAL)托盘窗口,1s 一次
ensure_all_attached整链 z 序判定(见②);缺宿主时延迟创建窗口
needs_representpresented/attached 缺失 → 用现有表面 ULW 重呈现(毫秒级),无表面才全量重绘
reconcile_desktop_icons栅栏呈现异常 → 恢复原生图标(绝不空白桌面)
sync_icon_sizeLVM_GETITEMSPACING 实测格距(10s 缓存,别每秒骚扰 Explorer)
壁纸跟随(3s)+ 签名轮询(1s)见④
rescan(watcher dirty 或 30s)文件集合无变化直接返回;有变化才清缓存+重排+入场动画

⑨ 退出链路退出 / 崩溃 / Explorer 重启

托盘菜单"退出"或 WM_CLOSEquit_app
存档壁纸快照落盘(此刻图标隐藏,快照干净)+ 使用统计 + 布局
恢复原生桌面显示原生图标、清接管标记、删托盘图标、消息循环结束
崩溃自愈:下次启动发现标记的 PID 已死 → 自动恢复原生图标(log "restored desktop icons from previous dead session")。Explorer 重启:taskbar_created 消息 → 恢复原生桌面 → 重挂栅栏 → 重加托盘。自救命令:deskfence.exe --restore-desktop。
